# DSH Visual Studio

> **一个用于 DeepSeek-Harness 的可视化 Harness / Preset / Plugin / Runtime 编辑器。**
项目暂定：

```
dsh-visual-studio
```
核心理念：

> **不要把 Agent 当 Workflow 编辑，而是把 Agent Harness 当作一个可组合、可观察、可评估的 Runtime System。**

# 四、节点模型
我建议不要直接使用 React Flow 的 Node 当领域模型。
建立一个独立的：

```
Harness Graph DSL
```
例如：

```
{
  "id": "preset-coding-agent",
  "version": "1.0",

  "nodes": [
    {
      "id": "model-1",
      "type": "model",
      "plugin": "deepseek-model",
      "config": {
        "model": "deepseek-chat"
      }
    },
    {
      "id": "loop-1",
      "type": "agent-loop",
      "plugin": "default-agent-loop"
    },
    {
      "id": "memory-1",
      "type": "memory",
      "plugin": "memory-plugin"
    }
  ],

  "edges": [
    {
      "from": "model-1",
      "to": "loop-1",
      "type": "service"
    }
  ]
}
```
重点是：

> **Canvas Graph ≠ Domain Graph**
Canvas 只是：

```
Visualization Projection
```
真正的数据模型应该独立存在。

# 五、Connection 不应该只有一种
这是这个编辑器区别于 Langflow 的关键。
建议支持 5 种边。

## 1. Service Dependency

```
Memory
   │
   │ service
   ▼
Agent Loop
```
表示：

```
A provides
B consumes
```

---

## 2. Event Flow

```
Tool
 │
 │ tool.executed
 ▼
Memory
```

---

## 3. Context Flow

```
Memory
   │
   │ context
   ▼
Model
```

---

## 4. Data Flow

```
Tool Result
      │
      ▼
Context Builder
```

---

## 5. Lifecycle Dependency

```
Plugin A
    │
    │ initialize before
    ▼
Plugin B
```
因此 Edge：

```
type EdgeType =
  | "service"
  | "event"
  | "context"
  | "data"
  | "lifecycle"
```
这会让它从一个普通的 Agent Builder 变成：

> **Agent Runtime Architecture Editor**

# 六、Plugin Introspection Engine
这是整个项目最重要的 Backend。
目标：
自动读取 Plugin。

```
Plugin
   │
   ▼
Metadata
   │
   ├── Config Schema
   ├── Dependencies
   ├── Services
   ├── Events
   ├── Lifecycle
   └── Capabilities
```
统一输出：

```
interface PluginManifest {
  id: string
  name: string
  version: string

  category:
    | "model"
    | "loop"
    | "memory"
    | "tool"
    | "storage"
    | "ui"

  configSchema: JSONSchema

  provides: Service[]

  consumes: ServiceRequirement[]

  events: EventDefinition[]

  lifecycle: LifecycleDefinition[]
}
```
这样 UI 就可以完全自动生成。
